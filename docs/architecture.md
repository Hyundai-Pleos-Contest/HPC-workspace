# 저장소와 실행 경계

Android 앱이 Pleos/AAOS API에 접근한다. 차량에서 필요한 데이터를 서버에 보내는 계약은 기능 설계 시 정한다.
외부 API 진입점은 BE를 기본으로 한다. AI는 필요할 때 BE에서 호출하는 내부 서비스로 확장한다.

| 저장소 | 소유 대상 |
| --- | --- |
| HPC-fe | Android 화면·상태, 차량 접근 계층, 앱 빌드 |
| HPC-be | 공개 API 계약, 업무 흐름, DB migration, BE Dockerfile |
| HPC-ai | 모델·프롬프트·평가, AI 입력·출력 계약, AI Dockerfile |
| HPC-workspace | 공통 정책, 통합 Compose, 실행 안내, 호환 버전 조합 |

BE는 단일 Spring Boot 애플리케이션으로 시작한다. 실제 기능이 생길 때 기능별 패키지를 나눈다.
AI 저장소의 존재가 별도 GPU·모델·상시 서버를 요구하지 않는다.

## 계약
- API 명세는 서비스를 제공하는 저장소에서 관리한다.
- 시간/좌표/속도·거리 단위, nullable 값, 오류 코드와 timeout은 계약에 명시한다.
- workspace에는 링크와 호환 버전을 기록한다.
- 호환성 변경은 제공자 확장 → 소비자 전환 → 이전 계약 제거 순으로 진행한다.
- 모델 원본, 실제 차량 로그와 개인정보는 기본 Git 관리 대상이 아니다.
