# 통합 버전 기록

각 저장소는 독립 버전으로 관리한다. 초기 세팅에는 제품 릴리스 태그를 자동 발행하지 않는다.

제출·시연할 때 해당 작업의 문서에 다음을 기록한다.
- FE/BE/AI의 정확한 commit SHA와 필요한 tag.
- 소스 SHA로 빌드한 APK·서버 이미지의 위치와 식별자.
- 모델·프롬프트·API 계약 버전. 사용하지 않으면 해당 없음.
- SDK·에뮬레이터 버전과 실제 연동/mock 여부.
- 실행 설정의 이름, 시연 데이터 버전과 시연 절차. 비밀값은 제외.
- 실제 실행한 통합 검사와 남은 제한.

변경이 없는 저장소에 동일 번호의 릴리스나 태그를 억지로 생성하지 않는다.
